## 📋 Project Overview

**What is this project?**
Medical Health Dashboard is an interactive web application that provides three evidence-based health calculators in one clean interface.

**Why was it built?**
As a medical student passionate about open-source technology, I built this project to bridge the gap between clinical knowledge and software development — making medical calculations accessible to everyone.

---

## ✨ Features

- 🔢 **BMI Calculator** — with WHO classification and ideal weight estimation
- ❤️ **Heart Rate Zones** — 5 training zones based on age and maximum heart rate
- 💧 **Hydration Tracker** — daily water intake adjusted for weight and activity level
- 📱 Responsive design — works on mobile and desktop
- 🌙 Dark mode medical-themed UI
- 🩺 Clinical notes explaining the medical context of each metric

## 🧪 Medical Formulas Explained

### 1. BMI — Quetelet Index

```
BMI = weight (kg) / height² (m)
```

| BMI Range | Category |
|-----------|----------|
| < 18.5 | Underweight |
| 18.5 – 24.9 | Normal weight ✅ |
| 25.0 – 29.9 | Overweight |
| ≥ 30.0 | Obese |

> ⚠️ BMI is a screening tool, not a diagnostic measure.

---

### 2. Ideal Body Weight — Devine Formula

```
Female: IBW = 45.5 + 2.3 × (height in inches − 60)
Male:   IBW = 50.0 + 2.3 × (height in inches − 60)
```

---

### 3. Maximum Heart Rate — Tanaka Formula

```
Max HR = 208 − (0.7 × age)
```

| Zone | % of Max HR | Purpose |
|------|------------|---------|
| Z1 — Recovery | 50–60% | Active recovery |
| Z2 — Aerobic | 60–70% | Base endurance |
| Z3 — Tempo | 70–80% | Aerobic power |
| Z4 — Threshold | 80–90% | VO2 max improvement |
| Z5 — Maximum | 90–100% | Neuromuscular power |

---

### 4. Daily Water Intake

```
Water (mL) = 35 mL × weight (kg) × activity factor
```
